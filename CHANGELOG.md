# Changelog

All notable changes are recorded here. The project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-25
### Added
- Initial public release.
- Modules: `acquisition`, `catalog`, `io`, `qc`, `calibration`, `spectral`, `indices`, `segmentation`,
  `plots`, `pointcloud`, `thermal`, `ml`, `deep`, `validation`, `pipeline`, `cli`, `datasets`, `synthetic`.
- Checksum-pinned downloaders for AVIRIS Indian Pines and Salinas, CWFID and Pheno4D (single-file extraction
  by HTTP range requests).
- Synthetic five-crop, three-platform trial with 13 injected faults.
- Tutorials 00–05, MATLAB interop functions, 29 unit tests, GitHub Actions CI.
